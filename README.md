# استمارة EMIS — إرسال إلى تيليجرام

نسخة من استمارة تحديث بيانات الطلبة (مدرسة قطر) ترسل البيانات والصور إلى بوت تيليجرام.

## التشغيل

```bash
npm install
npm start
```

ثم افتح: http://localhost:3000

## إعداد تيليجرام

1. ضع توكن البوت في ملف `.env` (انظر `.env.example`).
2. افتح البوت في تيليجرام وأرسل `/start`.
3. افتح http://localhost:3000/setup.html واضغط «جلب معرف المحادثة».
4. انسخ الـ Chat ID إلى `.env` كـ `TELEGRAM_CHAT_ID=...`
5. أعد تشغيل السيرفر.

## أمان

لا تشارك توكن البوت علناً. إن تسرب، ألغِه من BotFather وأنشئ توكن جديد.
